# Морской бой (Battleship) - в процессе разработки

Классическая игра «Морской бой» с графическим интерфейсом, реализованная на Python. Игрок сражается против компьютера, расставляя свои корабли и пытаясь уничтожить флот противника.

## Быстрый старт

### Требования

- Python 3.8 или выше
- Виртуальное окружение (рекомендуется)

### Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ArinaIMA/BattleShip.git
cd battle_ship
```

2. Создайте и активируйте виртуальное окружение:
```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Mac/Linux
python -m venv .venv
source .venv/bin/activate
```
3. Установите зависимости:
```bash
pip install -r requirements.txt
```
4. Запустите игру:
```bash
python main.py
```
